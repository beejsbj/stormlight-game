# Stormlight game

A fan-made, story-led party RPG adapting Brandon Sanderson's *The Stormlight Archive*. Made by Burooj and Ashar, with AI help. It's unlicensed fan work, not for sale.

This repo is our **workspace**: the design bible, decisions, sources and assets. The game itself will live in a separate repo once there's an engine prototype.

## Layout

| Path | What goes there |
|---|---|
| `docs/brief.md` | Sources, inspirations and positions so far. Start here. |
| `docs/adr/` | The big decisions, one file each: those that are hard to reverse, surprising, or a real trade-off. Everyday decisions live in GitHub issues. |
| `docs/bible/` | The design bible: world, characters, mechanics, art direction. |
| `docs/sources/` | Raw inputs: call transcripts, reference notes. |
| `assets/` | Concept art, renders, reference images, models. |

## How we work

- **Tasks** are GitHub issues. There's no checklist file.
- **Branches:** each of us experiments on our own branch. Merge to `main` what we both want to keep.
- **AI sessions** (Claude, Wayfinder, etc.) write their results into these files, not just into chat. Any session can be thrown away; the repo holds the record.
