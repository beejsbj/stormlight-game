# Reference library (book text)

Converted text of the books, for checking lore and reading scenes firsthand. **It must never be committed to this repo, which is public, or to any other repo.** Quote briefly and cite chapters.

- Mac: `/Users/burooj/BJsWorkspace/stormlight-reference/`
- bjslab: `/home/admin/stormlight-reference/` (`ssh bjslab`)
- Contents: all seven Stormlight Archive books, one Markdown file per chapter with an `index.md` per book. Files are named like `079-ch67-words.md`, so you can grep for `ch67`. Also the nine Cosmere RPG PDFs as text, with `=== page N ===` markers.
- Originals: the Grimmory library on bjslab, `/mnt/server-ssd/library/media/books/`. Don't modify anything in it.
- Conversion scripts: bjslab `~/stormlight-reference-tools/`.
